# ESG Report Auditor｜ESG 報告書邏輯與準則查核器

這是一份可重複使用的 **永續報告書查核 Prompt**，用於檢查報告書內部一致性、GRI 與 SASB 準則符合度，以及 ESG 評鑑中要求於永續報告書揭露的項目。

> 本專案目前提供 Prompt 範本，不是可自動執行的查核程式；查核結果仍須依實際提供的資料、適用準則與版本進行專業複核。

## 檔案
- [`ESG_Report_Audit_Prompt.md`](ESG_Report_Audit_Prompt.md)：完整版查核 Prompt。

## 使用方式
1. 開啟並複製 `ESG_Report_Audit_Prompt.md` 的內容到 AI 對話工具。
2. 填寫公司、年度、產業、適用 GRI／SASB 版本、ESG 評鑑年度等欄位。
3. 提供永續報告書與**適用版本**的 GRI、SASB、ESG 評鑑指標原始文件，並註明文件版本與來源。
4. 要求依序產出：**內部一致性查核表、GRI／SASB 符合度查核表、ESG 評鑑查核表**，以及發布前修改清單。
5. 由相關部門確認待查證事項後，再交由撰稿、美編與查核人員修訂。

## 查核重點
- **內部一致性：** 數據、單位、邊界、時點、政策與成果是否跨章節一致。
- **GRI：** 逐項比對揭露要求與子項，不只搜尋關鍵字。
- **SASB：** 核對適用產業的指標、單位、定義、計算口徑與活動指標。
- **ESG 評鑑：** 先辨識規定的揭露或佐證平台，僅對明確要求於報告書揭露的項目進行報告書符合度判斷。

## 查核原則
所有結論應附上原文證據與頁碼；缺少準則依據不得臆測；規劃中不等於已完成；未查得不等於公司未執行；不同文件矛盾時應列出證據並標示待確認。

## 注意事項
- ESG 評鑑是否得分由當年度正式指標、佐證規則與評鑑機構判定；Prompt 的建議不是保證得分。
- 本儲存庫公開分享 Prompt，但請勿上傳未經授權公開的公司內部文件、個資或機密佐證資料。
